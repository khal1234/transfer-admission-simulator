# 모바일 UI 점검 (390 × 844)

## 점검 범위

- 화면: 거점국립대 편입 성적 시뮬레이터 홈
- 대표 흐름: 성적 입력 → 입결 차트 확인 → 지망 비교 → 학과 검색
- 사용자 목표: 휴대폰에서 빠르게 학과를 찾고 지망에 담은 뒤 내 점수와 비교하기

## 현재 화면 근거

1. `01-home-top-390x844.png` — 첫 화면과 성적 입력 진입부
2. `02-score-chart-390x844.png` — 입결 차트
3. `03-basket-390x844.png` — 지망 비교 카드
4. `04-explorer-top-390x844.png` — 학과 탐색 기본 상태
5. `05-explorer-search-390x844.png` — “컴퓨터” 검색 결과

## 전체 판정

성적 입력과 지망 비교는 사용할 수 있지만, 모바일의 핵심 작업인 학과 탐색 표가
너무 좁게 압축되어 읽기와 “지망 추가”가 어렵다. 모바일 화면 높이는 약 5,892px이며
학과 탐색은 상단에서 약 2,378px 아래에 시작한다. 차트는 Y축 숫자가 잘리고, 지망
카드는 정보 밀도가 높아 여러 학과를 비교하기 어렵다.

## 단계별 상태

### 1. 첫 화면과 성적 입력 — 보통

- 입력 컨트롤은 한 열로 배치되어 이해하기 쉽다.
- 365px 높이의 헤더와 긴 주의문 때문에 첫 화면에서 핵심 입력이 충분히 보이지 않는다.
- 긴 주의문은 요약문과 “자세히 보기”로 접어야 한다.

### 2. 입결 차트 — 개선 필요

- 차트 제목, 지표 선택, 닫기 버튼이 한 줄에 몰려 제목이 여러 줄로 끊긴다.
- Y축 왼쪽 숫자가 잘린다. 차트의 음수 왼쪽 여백 설정이 직접 원인이다.
- 모바일에서는 차트를 기본 노출하지 말고 지망 카드의 “입결 추이”를 눌렀을 때
  펼치거나 전체 폭 바텀시트로 여는 편이 낫다.

### 3. 지망 비교 — 보통

- 합격선과 내 점수의 차이는 눈에 잘 들어온다.
- 한 카드가 약 834px로 길고, 11~12px 본문과 표가 조밀하다.
- 첫 상태에는 합격선 차이와 상태만 보이고, 역산 분석과 3개년 표는 접어서
  “상세 분석 보기”로 제공하는 것이 좋다.

### 4. 학과 탐색과 검색 — 심각

- 6열 데스크톱 표가 348px 안으로 압축되어 헤더와 학과명이 세로 글자처럼 보인다.
- 표에 최소 너비가 없어 가로 스크롤도 생기지 않으며, 오른쪽 “지망 추가” 버튼이
  사실상 보이지 않는다.
- 모바일에서는 표를 카드 리스트로 바꿔야 한다. 한 카드에 대학·학과, 모집인원,
  TOEIC 평균, GPA 평균, 전체 폭 “지망 추가” 버튼을 배치한다.
- 대학 필터는 여러 줄 대신 한 줄 가로 스크롤 칩 또는 드롭다운으로 줄인다.

## 권장 모바일 정보 구조

1. 축약 헤더
2. 내 성적 입력
3. 학과 검색과 대학 필터
4. 학과 결과 카드와 지망 추가
5. 하단 고정 “지망 보기 (N)” 버튼
6. 지망 비교 요약
7. 필요할 때 펼치는 역산 분석·3개년 표·차트

## 우선순위

1. 학과 탐색 표를 모바일 카드 목록으로 전환
2. 모바일 순서를 입력 → 탐색 → 지망 비교로 변경
3. 차트 Y축 잘림과 헤더 배치 수정
4. 헤더 주의문과 상세 분석을 접을 수 있게 변경
5. 터치 대상 최소 44px, 본문 최소 13~14px, 카드 좌우 여백 16px 적용

## 확인 한계

스크린샷과 로컬 화면 구조를 기준으로 점검했다. 실제 iOS Safari·Android Chrome의
키보드 표시, 확대 200%, 스크린리더 읽기 순서, 포커스 표시, 실기기 성능은 별도
검증이 필요하다.

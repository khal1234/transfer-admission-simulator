# 충북대학교 편입학 모집요강 ↔ 저장값 2차 대조 (2024~2026)

- 확인일: 2026-08-01
- 범위: `results/편입_환산공식_통합.json`, 웹 사본, 실제 환산 코드, 일반/예외학과 분류
- 원문: 충북대학교 입학처가 게시한 각 학년도 대학 편입학 모집요강

## 후속 구현 반영 상태

2차 대조 당시 계산 코드가 지원하지 않아 예외 데이터로 분리했던 전공필기형과
실기형을 연도·학과별 공식으로 구현했다. 이에 따라 충북대 결과 150행을 모두
정상 지원 데이터로 복원했으며, 현재 충북대 예외 행은 0건이다. 아래의
“예외 데이터로 이동” 기록은 오류 발견 당시의 감사 이력이다.

## 연도별 원문과 확정값

### 2024학년도

- [공식 모집요강 PDF](https://ipsi.chungbuk.ac.kr/preview/1709649881200/index.html)
- 근거: PDF 31쪽(전형요소·공인영어), 33쪽(전적대 성적)
- 일반학과 최종전형: 공인영어 30 + 전적대 30 + 면접·전공구술 40 = 100점
- 공인영어: `10 + (공인영어 구간 환산점수 × 0.2)`
- 전적대: `10 + (백분율점수 × 0.2)`

수정한 불일치:

1. 저장 JSON의 `총점`과 `면접구술`이 `null`이었음 → `100`, `40`으로 수정.
2. 실제 계산 코드가 TOEIC 구간표를 연속식으로 근사했음 → 원문의 구간표를 그대로 조회하도록 수정.
3. 원문은 TOEIC 375점 이하의 구간 환산점수를 22.5로 고정하므로 영어 반영점수 최저는 14.5점임. 기존 계산은 낮은 점수에서 10점까지 내려갔음 → 14.5점으로 수정.
4. 전적대가 2곳 이상일 때의 백분율·취득학점 가중평균식이 저장 설명에 빠져 있었음 → PDF 33쪽 산식을 추가.
5. 건축학과가 일반학과 데이터에 있었음 → 면접 10점·실기 30점 특수 배점 학과이므로 예외 데이터로 이동.

### 2025학년도

- [공식 모집요강 PDF](https://ipsi.chungbuk.ac.kr/preview/1733201205624/index.html)
- 근거: PDF 27쪽(전형요소·공인영어), 28쪽(전적대 성적)
- 일반학과 최종전형: 공인영어 30 + 전적대 30 + 면접·전공구술 40 = 100점
- 공인영어: `10 + (공인영어 구간 환산점수 × 0.2)`
- 전적대: `10 + (백분율점수 × 0.2)`

수정한 불일치:

1. 저장 JSON의 `총점`과 `면접구술`이 `null`이었음 → `100`, `40`으로 수정.
2. 실제 계산 코드의 연속 근사와 잘못된 최저점 → 원문 구간표와 14.5점 최저점을 적용.
3. 간호학과가 일반학과 데이터에 있었음 → 원문 27쪽에서 전공필기 20점이 포함된 특수전형으로 확인되어 예외 데이터로 이동.
4. 전적대가 2곳 이상일 때의 백분율·취득학점 가중평균식이 저장 설명에 빠져 있었음 → PDF 28쪽 산식을 추가.

### 2026학년도

- [공식 모집요강 PDF](https://ipsi.chungbuk.ac.kr/preview/1764319326867/index.html)
- 근거: PDF 26쪽(전형요소·공인영어), 31쪽(동점자·전적대 성적 산식)
- 일반학과 최종전형: 공인영어 60 + 면접·전공구술 40 = 100점
- 전적대 성적: 총점에 미반영(동점자 우선순위에는 사용)
- 공인영어: `40 + (공인영어 구간 환산점수 × 0.2)`

수정한 불일치:

1. 저장 JSON의 `총점`과 `면접구술`이 `null`이었음 → `100`, `40`으로 수정.
2. 실제 계산 코드가 공인영어를 추정 연속식으로 처리했음 → 원문의 구간표를 그대로 적용하고 신뢰도를 `verified`로 변경.
3. 원문상 TOEIC 375점 이하 영어 반영점수 최저는 44.5점인데 기존 계산은 40점까지 내려갔음 → 44.5점으로 수정.
4. 약학과·제약학과가 특수전형 예외로, 간호학과가 일반전형으로 분류돼 있었음 → 26쪽 배점표에 맞게 약학과·제약학과는 일반 데이터, 간호학과는 전공필기 20점 특수전형 예외 데이터로 이동.
5. 건축학과가 일반학과 데이터에 남아 있었음 → 면접 10점·실기 30점 특수 배점 학과이므로 예외 데이터로 이동.
6. 전적대 성적이 총점에는 미반영이라는 설명만 있었음 → 최종 동점자 판단에 사용되며, 전적대가 2곳 이상이면 백분율·취득학점 가중평균을 적용한다는 31쪽 내용을 추가.

## 계산 오차 예시

원문 구간표에서 TOEIC 980~990점은 환산점수 100점이다.

| 학년도 | TOEIC | 기존 연속 근사 | 원문·수정값 |
|---|---:|---:|---:|
| 2024·2025 | 980 | 29.81 | 30.00 |
| 2026 | 980 | 59.81 | 60.00 |
| 2024·2025 | 375 이하 | 최저 10.00까지 하락 | 14.50 고정 |
| 2026 | 375 이하 | 최저 40.00까지 하락 | 44.50 고정 |

## 일치한 내용

- 2024·2025 공인영어 산출식과 전적대 1곳의 산출식은 저장 JSON과 원문이 일치함.
- 2024·2025 공인영어 30점, 전적대 30점 배점은 일치함.
- 2026 공인영어 60점, 전적대 총점 미반영은 일치함.
- 세 학년도 공인영어 구간표는 동일함.
